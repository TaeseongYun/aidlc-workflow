# Knowledge Log (→ Linear)

**Append-only.** Distilled, reusable lessons learned while fixing hallucinations. Each lesson
is categorized and pushed to **Linear** (one Team, category as Label) via the Linear MCP.

- Category is exactly one of: `frontend` | `backend` | `ios` | `android` | `devops`.
- `Status`: `PENDING-LINEAR` (Linear MCP not authenticated yet) → `SYNCED` (issue created).
- When Linear MCP is unavailable, entries stay `PENDING-LINEAR`; run `/mcp` to authenticate,
  then re-run `/ctx-hallucination-audit` to flush the queue.

## Category routing heuristic

| Category | Signals |
|----------|---------|
| `frontend` | web UI, React/Vue/Svelte, CSS, components, browser APIs, routing (client) |
| `backend` | server, REST/GraphQL, DB/schema, auth, services, background jobs |
| `ios` | Swift, SwiftUI, UIKit, Xcode, Podfile, `.xcodeproj`, iOS SDK |
| `android` | Kotlin/Java (Android), Gradle, Jetpack/Compose, Android SDK/manifest |
| `devops` | CI/CD, Docker, k8s, Terraform, cloud infra, deploy pipelines, secrets/env |
