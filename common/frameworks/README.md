# PM Frameworks

A collection of PM frameworks that can be used optionally.
Reference as needed when writing planning-draft or requirements.

## Usage Principles
- Frameworks are supporting tools that help with question extraction and priority judgment.
- They do not replace team-ai-workflow's governance (no assumptions, approval gate).
- Apply a specific framework when the user requests it; otherwise, do not apply it automatically.

## Included Frameworks

| File | Purpose | When to Apply |
|------|------|----------|
| `rice.md` | Feature priority evaluation | When multiple features compete |
| `jtbd.md` | User needs analysis | When finding the true goal from a raw-request |
| `moscow.md` | Scope classification | When organizing In-Scope / Out-of-Scope |
